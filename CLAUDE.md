# Project instructions

## Commit messages

Use [Conventional Commits](https://www.conventionalcommits.org/) for all commit messages in this repo (e.g. `feat: add taskbar entries for open windows`, `fix: prevent icon labels from overlapping`).

Do not add any Claude/AI attribution to commits or PRs — no `Co-Authored-By: Claude`, no session links, no "Generated with Claude Code" footers. Do not mention Claude in commit messages or PR descriptions at all, unless I explicitly ask for it.
